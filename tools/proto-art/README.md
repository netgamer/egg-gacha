# 리얼 판타지 드래곤 파트 파이프라인 (proto-art → production)

`projects/egg-gacha`의 드래곤 파츠는 **한 장의 마스터 앵커 페인팅**에서 파생됩니다.
이 폴더는 그 파츠를 생성하고, 6슬롯 RGBA로 매트하고, 앱이 쓸 WebP 번들 + 카탈로그를 내보내는
프로덕션 파이프라인입니다. (처음엔 3테마 × 6슬롯 프로토타입이었고, 지금은 12파츠 × 6슬롯 = 72장입니다.)

| `shots/proto-real-dragon-themes.png` | 같은 테마 12종 (4×3) |

## 구조

레이어 순서(뒤 → 앞): `bg → wings → body → eyes → horns → acc`

- `master/base.png` — 1122×1402 3/4 버스트, **뿔 그루터기 제거**, 균일 회색 판, 빈 눈 소켓. 모든 파츠의 픽셀 기준.
  (`master/base-orig.png`는 뿔이 있던 원본)
- `gen.py` — `images --edit master/base.png`로 파츠별 변형을 만듭니다. 프롬프트가 포즈·카메라·크롭·조명을 고정하고
  한 슬롯만 바꾸므로, 변형에서 달라진 픽셀이 곧 그 슬롯의 파츠입니다. 변형마다 실루엣 IoU를 측정해 `out/gen-report.json`에 남깁니다.
- `pipeline.py` — 변형 → RGBA 파츠 → WebP/썸네일/카탈로그 + QC.

## 매트에서 중요한 것

생성 모델은 회색 판 위에 옅은 그라디언트를 남기고, 옅은 뿔·날개는 판과 밝기가 거의 같습니다.
그래서 **색 임계값만으로는 매트가 반드시 실패**합니다. 대신:

- `bg_flood(v)` — 테두리에서 시작해 **엣지를 넘지 못하는** 플러드필로 배경을 찾습니다. 그라디언트에 강합니다.
- `plate_field(v)` — 찾은 배경을 push-pull로 파츠 뒤까지 확장한 "판 예상값". 이와의 차이로 날개·뿔을 땁니다.
  판 안쪽에 갇힌 회색 웅덩이도 자동으로 배제됩니다.
- `notch` — 턱과 목 사이의 목구멍 홈(판이 보이는 부분)은 마스터에서 한 번 찾아 모든 파츠에서 제외합니다.
  이걸 빼면 크로스 조합에서 회색 판 조각이 목에 붙습니다.
- `eyes` — 검은 소켓과 밝기가 비슷한 어두운 눈은 차이로 잘리지 않아, **소켓 타원**을 알파로 쓰고 번지는 빛만 더합니다.
- `acc` — 얇은 사슬·필리그리가 임계값 아래로 사라지지 않게 밴드를 살짝 키운 뒤 변화 픽셀로 되깎습니다.
- `body` — 변형 자체의 안티앨리어싱 윤곽에서 소프트 알파를 뽑고, 프레임 아래에서 끊기면 이어 붙입니다.
- `wings` — 몸 실루엣 밖 + 판이 아닌 영역. 몸이 앞에서 덮으므로 목 경계에서 새지 않습니다.
- `horns` — 실루엣 밖으로 자란 부분 + 뿔이 실제로 닿는 크라운 밴드(고주파 차이)만. 볼·턱·목은 body 소유로 남깁니다.

## "붙여넣기"를 지우는 합성 패스

파이썬 `compose()`와 앱의 `src/dragon-compose.js`가 같은 순서로 마감합니다.

1. 환경 림 라이트 (배경의 밝은 영역을 실루엣 바깥 밴드에 screen)
2. 라이트 랩 (배경광이 실루엣 안쪽 가장자리로 스며들게)
3. 환경 톤 패스 (배경의 저주파 색을 곱해 한 조명 아래로 통일)
4. 블룸 / 접지 그림자 / 그레인 + 캔버스 텍스처 / 비네트 / 최종 그라데이드

## 실행

```bash
cd projects/egg-gacha/tools/proto-art
python3 gen.py                 # 변형 생성 (있는 파일 skip, -j 4 병렬)
python3 gen.py magma eyes      # 한 파츠만
python3 pipeline.py parts      # 매트 + WebP/썸네일 + 카탈로그 + QC
python3 pipeline.py export     # out/layers에서 번들만 다시 내보내기
python3 pipeline.py atlas      # 낱개 파츠 아틀라스
python3 pipeline.py mix        # 기본 몸 위에 파츠별로 얹어 보기 (매트 점검)
python3 pipeline.py sheet      # 테마/크로스 시트 + 카드 클로즈업
```

## 알려진 한계

- `STRAY_REJECT`는 파츠별 수동 매트 자리입니다(현재 비어 있음). QC 플래그가 뜨면 여기에 영역을 적어 잘라냅니다.
- 뿔은 "실루엣 밖 + 크라운 루트"만 가져오므로, 뿔이 두개골 안쪽에서 크게 자란 디자인은 일부가 잘립니다.
  뿔 디자인은 "관 위로 솟는" 형태로 유지하는 편이 좋습니다.
- 파츠 생성은 파츠당 약 12초(`images --edit`)입니다. 72장이면 병렬 4로 8~10분.
